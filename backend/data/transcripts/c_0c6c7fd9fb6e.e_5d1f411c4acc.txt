世界每天都在刷屏，听懂世界只要随行。Hello, 大家好，欢迎来到这一周的世界，这七天我是飞，赶紧来看世界这一周又发生了什么？在上周一，美国总统特朗普表示，美国政府已经批准英伟达向中国出售英伟达产品中第二先进的芯片H20。美国政府数月来一直在权衡是否要放宽对华销售政策，这将影响到中美竞争的结果。特朗普在社交媒体上发文称，美国商务部正在敲定相关的细节，并且也将为AMD、英特尔等其他芯片制造商也提供类似的出口机会。他还表示对华芯片销售收入的一部分将会归美国政府所有。有专家指出这一提议可能违反美国的法律。但是无论如何，这一决定对英伟达的CEO黄仁勋而言肯定是一个重大胜利。他数月来一直在游说白宫放宽出口限制。那如今的问题就是中国会购买吗？中国政府向来不鼓励企业购买美国的芯片，有关部门警告称美国芯片可能存在安全风险。



host   01:21

虽然现在看似美国是创造了最强大的人工智能AI模型，并且控制着最先进计算机芯片的获取渠道。但是在全球AI竞赛当中，中国其实也握有一张王牌。这张王牌就是中国现在拥有世界有史以来最大的电网。2010年至2024年期间，中国的发电量增幅超过了世界其他地区的总和。去年中国发电量是美国的两倍多一些，中国数据中心现在支付的电费不到美国数据中心的一半。中国国家数据局局长刘烈宏今年3月表示，在中国，电力是我们的优势，中国对电力领先地位的追求正在重塑内蒙古偏远广袤的地区。在这片类似得克萨斯州的开阔地貌上，成千上万的风力涡轮机与纵横交错的输电线网正在为官方所描绘的新草原、云谷提供电力，那里有上百座已经投入运营或者正在建设的数据中心。这还只是个开始。摩根斯坦利预测，截至2030年的五年里，中国将在电网项目上支出约5600亿亿美元，较此前的五年增长45%。高盛则预测，到2030年，中国将会拥有约400吉瓦的富余发电能力，约为那个时候全球数据中心预期电力需求的三倍。



host   02:50

现在，所谓的中美电力鸿沟已经成为美国科技领域的一大关键问题。微软的首席执行官纳德拉已经表示，微软担心没有足够的电力来运行它购买的海量芯片。一些公司希望华盛顿方面能够采取更多的措施，减少繁文缛节或者提供政府的财政支持来推动美国电网的现代化。摩根士丹利预测，未来三年美国数据中心可能会面临44G瓦的电力缺口，相当于纽约州夏季的发电能力，这对美国的AI雄心构成了严峻挑战。而在中国，廉价的电力已经助力deep seek等AI公司以低于美国竞争对手的成本开发出高质量的AI模型。中国也试图借此来克服国产计算机芯片性能较差带来的挑战，通过将这些芯片大量的捆绑在一起，就可以在性能上逼近英伟达制造的先进芯片，但是这个过程中需要消耗多得多的电力。美国总统特朗普在上周宣布放宽向中国出口H200芯片，这款芯片并非英伟达最顶级的芯片，但是仍然要优于中国目前最好的国产芯片。



host   04:06

中国在电力领域的发力源于中国政府在2021年公布的东数西算工程。该工程主张利用中国西部丰富的电力资源来满足东部人口稠密地区由AI驱动的大量需求。中国还力争到2028年将数以百计的数据中心连接起来，建立一个全国共享的算力池，一些人称之为国家云。这项达几十亿美元的计划支出，再加上部分电力和数据中心，算力其实并没有被充分的利用，也引发了对中国产能过剩和市场泡沫的担忧。但是，中国官员寄希望于国家规划能够缓解这些风险。



host   04:48

中美现在面临的共同挑战是，数据中心正在以前所未有的速度吞噬着国家的电力，而需求上限难以预估。开发AI是一个非常耗电的过程，聊天机器人的每一次应答都需要电力来驱动AI模型最快到2030年，中国数据中心的年耗电量预计将与法国全国的总耗电量相当于美国数据中心的用电需求甚至更大。根据国际能源署的数据，去年美国数据中心占全球数据中心用电量的45%，中国占25%。



host   05:25

中国扩大电网的行动最早可以追溯到20世纪70年代。当时中国领导人担心电力短缺会阻碍国家发展，于是引导国有企业建造了数以百计的燃煤发电厂。后来，他们又押注于可再生能源，为大型的水电项目、太阳能发电厂和风力发电厂提供资金。由于最佳选址往往远离东部人口中心，中国还架设了世界上最大的特高压输电线路网络。据官方媒体报道，自2021年以来，中国在这方面已经投资了超过500亿美元。



host   06:03

中国目前的发电装机容量为3.7 5000瓦，是美国的两倍多。根据世界核能协会的数据，中国还有34座核反应堆正在建设中，另外有近200座已经列入规划或者提议。在西藏，中国正在建设世界上最大的水电项目，预计发电量可以达到三峡大坝的三倍。根据中国国家能源局称，通过长期的购电协议，中国数据中心现在能够以低至每千瓦时3美分的价格获得电力。而在美国，在弗吉尼亚州北部等城市，同样的电力通常需要支付每千瓦时7至9美分，要是中国的三倍。但是在另外一方面，巨额的能源支出正在加剧中国的债务负担，成为中国经济发展的拖累。从2019年初到2024年底，国有电网运营商国家电网的债务和其他负债增长了40%以上，负债达到约4500亿美元。



host   07:03

在美国，一些科技公司正在为数据中心自建发电厂，特朗普也已经承诺要与中国的电力建设步伐旗鼓相当。一位白宫发言人说，特朗普的目标之一包括使美国在赢得AI竞赛的同时降低能源价格，并且提高电网效率。但是扩建电网绝非易事。美国太阳能协会在11月的一封信中对美国能源部表示，美国作为全球AI领导者的地位，现在正因为繁琐且不稳定的许可政策以及输电能力不足而受到阻碍。该行业组织称，包括美国数据中心主要聚集地在内的18个州，超过一半的规划太阳能和储能容量都面临受阻的风险。



host   07:52

而在中国，情况就完全不同。内蒙古的乌兰察布市和邻近的和林格尔县位于北京西西北约200英里处，被指定为中国政府东数西算工程的八大枢纽节点地区之一。其中许多地区是因为能够在那里获得廉价的电力而被选中，他们被选中后，正好也为这些比较贫困的地区引入了投资，也就是说，外面的企业需要这些内陆地区的廉价电力，这些内陆地区则正好需要外来投资，这是一个双赢的局面。中国政府已经要求企业只能够在这些枢纽节点建设新的数据中心，并且在监管、审批和土地征用方面会给予优先考虑。数据中心有时候只需要支付一半的电费，其余部分都由政府来补贴。



host   08:44

在乌兰察布，由于当地的就业岗位缺乏，导致人口在2019年至2024年期间减少了4分之1，降至160万人。但是如今许多人在那里嗅到了商机。该地区气候凉爽，对数据中心而言堪称理想，降低了空调和水冷的能耗，开阔的地貌也非常适合建设太阳能和风力发电厂。当地的一家餐馆老板说，等未来更多的数据中心陆续建成，应该是会一年比一年好了。过去五年，乌兰察布的地区生产总值已经增长了50%，从2019年到去年年底，数据中心和其他信息技术服务所消耗的电力增长了七倍多。当地政府表示，截至今年6月，该市已经吸引了350亿美元的算力产业投资。



host   09:34

11月，如果沿着乌兰察布市市中心以东的110国道驱车而行，你可以看到这一地区的快速变化。在道路的一侧建筑中还有很多是空置的，只有几家简陋的餐厅和一些卖香烟的商店。但是在道路的另一侧，你可以看到中间数据所运营的数据中心。该公司还在该地区架设了风力涡轮机和太阳能电池板。该数据中心在破土动工仅16个月后就投入了运营，为北京的很多客户提供云计算服务。苹果公司、阿里巴巴和华为也在这里设有数据中心，电动汽车生产商小鹏汽车等公司则在这里训练他们的AI模型和处理AI的工作负载。在距离乌兰察布市约两个半小时车程的和林格尔，国有电力巨头中国华电去年开始为一个数据中心集群开发电力基础设施。今年，这个耗资2.3亿美元的项目已经开始为中国最大的几家电信运营商以及一些云计算储存公司供电。



host   10:39

为了弥补国产芯片不如美国芯片先进的短板，华为、阿里巴巴和百度等中国公司希望通过将数千枚国产芯片捆绑在一起的系统来提升算力。要知道，让如此多的芯片高效协同的工作，你需要尖端的网络技术、复杂的算法以及大量的电力。这项任务极具挑战性，以至于英伟达两年前就因为成本过高功耗过大和可靠性较差而放弃了生产一款使用256枚芯片的系统。而中国的科技巨头现在正在挑战把上千枚芯片捆绑在一起，按照一种常用的规格来计算，捆绑了384枚升腾芯片的华为系统提供的算力要比英伟达捆绑72枚blackwell芯片的旗舰系统高出3分之2。但是分析公司称，华为系统的功耗是英伟达的四倍。使用过华为这一款cloud matrix 384系统的工程师则表示，该系统安装和操作十分的复杂。有一些人说，对于训练大规模AR模型而言，华为的系统仍然不够实用和流畅。



host   11:50

据中国科技公司的业内人士称，这一策略要奏效所面临的主要障碍是，中国还是无法足够快地生产出最顶尖的芯片。分析师预测，高端芯片的短缺情况至少还将持续几年。目前尚不清楚中国将购买多少英伟达的H20芯片，以及美国对高端芯片出口限制的变化将在多大程度上改变现状。中国政府已经表示要致力于开发自己的国产先进芯片。半导体行业分析师表示，短期来看，与美国的电力瓶颈相比，中国缺乏尖端芯片产能是更加严峻的一个制约因素，但是中国的发电能力使得中国能够继续参与竞争，而AI竞赛持续的时间越长，中国缩小差距的机会就越多。



host   12:45

同样在上周，知名企业家李开复在英国的金融时报上发表了一篇文章，称中国的开源AI具有独特的优势。他说今年1月中国的大模型公司deep sick发布大语言模型的时候，美国纳斯达克指数就曾经出现了单日3%的下跌。因为当时很多人没有想到，中国这么快就做出了自己的类似ChatGPT的东西。这似乎暗示着美国在生成式AI领域的先发优势正在收窄。李开复指出，更加引人注目的是，deep sick的这款RE模型选择了开源，也就是说任何人都可以免费下载并且用于商业用途。他认为中国大模型公司能够与美国同行进行全球竞争，原因之一就是开源模型在中国正逐渐成为行业的主流。百度、美团、月之暗面等公司都允许用户下载研究并且定制化的使用他们的顶尖开源模型。这种开源开放的做法与美国的大模型领域日趋封闭的开发模式形成了鲜明的对比，也为中国大模型行业提供了一种独特的有中国特色的破局模式。



host   14:01

随着越来越多的中国大模型公司选择开源自身的模型，整体产业发展正在显著加速。不同公司的工程师因此可以相互研究彼此的模型，并且在这一基础上独立开发和迭代出数千个变体。这使得AI研发者能够筛选整合不同模型的优点，逐步改良。李开复认为，这就好比拔尖的学生，不仅仅可以自己学习，还可以齐心组成一个学习小组来一起攻克难题。这使得中国的大模型企业有更多的杠杆去与美国的同行竞争。



host   14:38

美国在生成式AI领域建立的早期领先地位，是以经典的硅谷模式建立起来的。硅谷模式也就是说像OpenAI这样的公司是首先依托风投的巨额投资，然后去采购高性能的芯片，在招募顶尖的研究人才，在封闭的实验室中自己开发发出一个模型。而他们如今正在陷入一场赢者通吃的寡头竞争，各家都寄希望于打造性能最强的模型来挤压对手的空间，以此来建立市场的垄断地位。李开复指出，处于追赶状态的中国大模型行业则必须将重点放在多快好省的效率上，着力开发使用成本更优的模型，以生态打法来变道超车。



host   15:26

目前全球排名前十的开源模型几乎都来自于中国，以至于谷歌的前CEO埃里克施密特曾经发出警告，他说开源模型领域美国的人工智能企业可能会被中国反超。当然这一切并不意味着中国必然会在人工智能竞赛中超越美国。美国公司在研究领域仍然保持领先，美国企业的客户也愿意支付高昂的订阅费用来使用这些闭源的模型。同时美国公司可以畅通无阻的获取世界最顶间的芯片，这仍然是生成式AI不可或缺的硬件基石。因此李开复称未来人工智能大模型的发展格局，很可能类似于现在的手机操作系统领域的苹果与安卓之争。美国公司正在构建一个类似于苹果IOS的封闭生态系统，提供高价的精品服务。



host   16:22

而中国公司的发展路径则更加接近于谷歌的安卓系统，打造开放且可定制化的操作系统。虽然iphone在高消费的群体中广受欢迎且利润丰厚，但是覆盖更广的安卓系统现在却成为全球70%以上智能手机的操作系统。中国的人工智能企业正遵循类似的安卓策略，通过技术开放与合作，推动产品与服务的丰富性和覆盖率，以实现更大版图的行业竞争力和影响力。
